# UI screenshots

Drop PNG (or JPG/GIF) captures of the React Web UI in this folder. The README's
**Screenshots** section references these filenames — add the images with these exact
names and they will show up automatically:

| Filename | Suggested capture |
| --- | --- |
| `dashboard.png` | Dashboard — recent analyses + capability chips |
| `new-analysis.png` | New Analysis — drag-and-drop APK upload |
| `progress.png` | Progress — live per-stage pipeline |
| `findings.png` | Analysis workspace — Findings tab |
| `knowledge-graph.png` | Knowledge Graph tab |
| `assessment.png` | Assessment — decision-intelligence conclusions |

Tips:
- Capture at a consistent width (e.g. 1440px) so the grid looks even.
- Use a real analysis (e.g. the bundled test APK or Magisk) so the views show data.
- Prefer PNG for crisp UI text. Keep each image under ~1–2 MB.
- To use different names or more images, edit the **Screenshots** section in the root `README.md`.
